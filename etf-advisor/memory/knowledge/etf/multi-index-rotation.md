## 2. 核心算法（所有指数统一）

### 评分公式

```
score = NAV涨幅×10% + (-综合超额溢价)×80% + (-当前溢价)×10%
pool_score = score + bonus (池内) 或 score + default_bonus (池外)
```

### 轮动条件

```
IF (best_score - current_score) >= threshold:
  换仓到评分最高的ETF
```

### 数据口径统一

**统一起点:** 2025-01-01

所有指数的历史数据统计都以此日期开始，确保：
- 跨指数对标数据可比性
- 不因数据长度不同导致评分偏差
- 前期纳指数据积累优势不会过度影响新指数

**影响的计算：**
1. 历史平均溢价 - `get_multi_period_avg_premium()` 使用 >= 2025-01-01 的数据
2. 1Y净值涨幅 - `calculate_nav_return_1y()` 基期为 2025-01-01
3. 轮动模拟回测 - `simulate_rotation()` 起始日期为 >= 2025-01-01 后的第一个交易日
4. 推荐排名 - 所有指数的评分排序都基于统一期间的历史数据

## 3. 关键参数及调整方向

### 轮动加分 (bonus / default_bonus)

| 指数 | 当前值 | 调整方向 | 判断标准 |
|-----|------|---------|---------|
| NASDAQ | ±0.5 | ✅ 已验证 | 2.8年历史优于等权，无需调整 |
| SP500 | ±0.5 | ⏳ 待调整 | 对比轮动vs等权，分析收益来源 |
| NIKKEI | ±0.5 | ⏳ 待调整 | 与NASDAQ/SP500对比，调整竞争激烈度 |
| DAX | 0 | ✅ 固定 | 两只ETF都在池内，无加分必要 |

**调整逻辑:**
- 如果轮动策略alpha > 10% → 说明加分有效，保持或增加
- 如果轮动策略alpha < 0% → 加分过度，需要减小
- 如果轮动频率 > 30次/年 → 加分过小，导致切换阈值过低

### 切换阈值 (threshold)

| 指数 | 当前值 | 调整方向 | 判断标准 |
|-----|------|---------|---------|
| NASDAQ | 1.0% | ✅ 已验证 | 历史数据验证有效 |
| SP500 | 1.0% | ⏳ 待调整 | 参考NASDAQ，但可能需要更宽松 |
| NIKKEI | 1.0% | ⏳ 待调整 | 日本市场波动性较小，可能需要宽松 |
| DAX | 1.0% | ⏳ 待调整 | 两只ETF竞争不激烈，可能可以降低 |

**调整逻辑:**
- 如果轮动次数 > 30次 → 阈值过低，提高0.2%-0.5%
- 如果轮动次数 < 3次 → 阈值过高，降低0.2%-0.5%
- 适宜范围: 5-15次/年（含交易成本考虑）

## 7. 已知限制和后续改进

### 当前限制

1. **SP500期货数据稀缺** - 不影响评分，但限制期货链接度分析
2. **DAX流动性较小** - 两只ETF竞争有限，轮动优势可能不明显
3. **NIKKEI区域特异性** - 日本市场特性可能需要特殊考虑
4. **交易成本未明确计算** - 仅估算±0.025%，实际应考虑冲击成本

### 后续改进方向

1. **完善期货数据** - 提高SP500期货覆盖率
2. **增强流动性分析** - 对低流动性指数（DAX）采用不同策略
3. **引入区域特异性** - 对亚洲/欧洲指数的溢价特征建立模型
4. **动态阈值** - 基于市场波动率动态调整threshold
5. **多因子评分** - 增加成交量、波动率等因子到评分模型

## 9. 快速查询

### SQL查询轮动表现

```sql
-- 查看各指数轮动次数和周期
SELECT strategy, COUNT(*) as days, 
       SUM(switched) as switches,
       ROUND(SUM(switched)*1.0/COUNT(*)*252, 1) as switches_per_year
FROM rotation_index
WHERE date >= '2025-01-01'
GROUP BY strategy;

-- 查看最近轮动记录
SELECT date, strategy, holding_code, switched, 
       ROUND(rotation_value, 2), ROUND(equal_weight_value, 2)
FROM rotation_index
WHERE date >= '2026-05-01'
ORDER BY strategy, date DESC;

-- 查看评分最高的ETF
SELECT DISTINCT date, index_type, code
FROM (
  SELECT date, index_type, code, pool_score,
         ROW_NUMBER() OVER (PARTITION BY date, index_type ORDER BY pool_score DESC) as rn
  FROM rotation_scores
  WHERE date = '2026-05-17'
)
WHERE rn = 1 AND index_type IN ('NASDAQ', 'SP500', 'NIKKEI', 'DAX');
```
